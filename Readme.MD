## Intel UI Templates — README

This repository contains the UI templates for the Intel feature revamp.

### Features

1) Bios serial log, Postcode reading, System state and ATX
2) Vitrual desk and OS Flashing
3) PDU
4) Firmware Flashing
5) USB file sharing
6) Added app.py and service file to access the index template
